# Glossary

| Term | Definition |
|------|------------|
| **ADS-B** | Automatic Dependent Surveillance–Broadcast |
| **AIS** | Automatic Identification System (maritime) |
| **ASTERIX** | All-purpose Structured Eurocontrol Surveillance Information Exchange |
| **Beast** | Binary protocol for ADS-B data (used by dump1090/readsb) |
| **CAT021** | ASTERIX category for position reports |
| **CAT048** | ASTERIX category for radar plots |
| **CAT062** | ASTERIX category for system tracks |
| **CAT034** | ASTERIX category for service messages |
| **CAT063** | ASTERIX category for ADS-B data |
| **CAT** | Category in ASTERIX standard |
| **CBV** | Code Block Version (EUROCONTROL) |
| **Decoding** | Converting binary data to structured format |
| **Encoding** | Converting structured data to binary format |
| **Encoding rule** | Rules for converting values to binary (e.g., scaling) |
| **ES** | Extended Squitter (ADS-B 1090 MHz) |
| **FSPEC** | Field Specification (ASTERIX) — bitmask of present fields |
| **Geo-fencing** | Restricting data to geographical area |
| **Hex / ICAO24** | 24-bit aircraft address (ICAO identifier) |
| **MLAT** | Multilateration — position from time difference of arrival |
| **Mode A/C** | Transponder modes for identification/altitude |
| **Mode S** | Selective addressing mode with data link |
| **NMEA** | National Marine Electronics Association (data format) |
| **ODIM** | Operational Data Information Model (weather radar) |
| **OGN** | Open Glider Network (FLARM-based) |
| **PSR** | Primary Surveillance Radar |
| **SBS-1** | BaseStation format (Kinetic) |
| **Sensor Hub** | NieboGuard Sensor Hub (local data aggregation server) |
| **Simulator** | NieboGuard Sensor Simulator & Protocol Lab |
| **Squitter** | Unsolicited transmission from transponder |
| **SSR** | Secondary Surveillance Radar |
| **TLV** | Type-Length-Value encoding |
| **UAT** | Universal Access Transceiver (978 MHz ADS-B) |
| **WSS** | WebSocket Secure |
| **Wanted Integration** | Community-requested feature not yet implemented |
