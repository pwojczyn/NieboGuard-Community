# FLARM (Flight Alarm)

## Introduction
FLARM is a collision avoidance system for gliders and small aircraft.

## Source
- https://www.flarm.com/
- FLARM protocol documentation
- OGN (Open Glider Network): https://wiki.glidernet.org/

## Status
NOT SUPPORTED
- Requires FLARM receiver
- Protocol proprietary (commercial)
- Potential future adapter planned
