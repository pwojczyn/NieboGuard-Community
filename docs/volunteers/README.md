# Wolontariusze

## Jak pomóc

- **Dokumentacja i tłumaczenia** — PL/EN, jasność, dostępność.
- **Testy** — SDK, narzędzia, przypadki brzegowe, dane syntetyczne.
- **ADS-B** — własny odbiornik, dump1090/readsb, test narzędzia GeoJSON.
- **Audio AI** — krótkie, legalne próbki z opisaną licencją; bez automatycznego
  uploadu i bez prywatnych rozmów.
- **Vision AI** — obrazy z jasną licencją, usunięte EXIF, ręczne etykiety.
- **Code** — SDK, narzędzia, walidacja, CI.

## Zadania

Zadania są opisane w GitHub Issues z etykietami:

- `good-first-issue` — mały start,
- `docs`, `sdk`, `adsb`, `audio`, `vision`, `tests`,
- `needs-review`, `blocked`, `help-wanted`.

Nie przyznajemy automatycznie punktów za sam PR. Reputacja powinna wynikać z
zaakceptowanej pracy i moderacji, nie z liczby kliknięć.

## Konta i GitHub

Nie tworzymy drugiego systemu kont. Docelowo istniejące konto NieboGuard może
zostać opcjonalnie połączone z GitHubem przez OAuth. Szczegóły i granice:
[`github-integration.md`](github-integration.md).

## Zasady danych

- Nie publikuj danych osobowych, prywatnych lokalizacji ani surowych nagrań.
- Próbki audio/wideo wymagają świadomej zgody i licencji.
- Dane demonstracyjne oznaczaj `synthetic: true`.
- Nie zgłaszaj zagrożeń wymagających natychmiastowej reakcji przez GitHub.
  W razie zagrożenia dzwoń 112 i kieruj się komunikatami służb.
