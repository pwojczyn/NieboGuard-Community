# Contributing

Dziękujemy za zainteresowanie NieboGuard Community.

## Zanim otworzysz PR

1. Sprawdź istniejące issues i dokumentację.
2. Dla większej zmiany otwórz issue z zakresem i uzasadnieniem.
3. Nie dodawaj sekretów, tokenów, `.env`, kluczy, APK, konfiguracji VPS ani
   danych użytkowników.
4. Nie dodawaj surowych współrzędnych prywatnych instalacji ani danych
   osobowych.
5. Nowe pliki są udostępniane na MIT; nie kopiuj kodu o niejasnej licencji.
6. Dodaj test lub wyjaśnij, dlaczego test nie jest możliwy.
7. Uruchom `python -m unittest discover -s tests -v` i
   `node --test tests/*.test.mjs`.

## Styl

- polski lub angielski; dokumentacja może mieć obie wersje,
- małe, tematyczne commity,
- bez reformatowania niepowiązanych plików,
- bez danych demonstracyjnych udających rzeczywiste zdarzenia,
- jasno oznaczaj dane syntetyczne.

## Pull Request

Użyj szablonu PR. Opisz:

- problem i rozwiązanie,
- wpływ na użytkownika,
- testy,
- licencję nowych plików,
- czy zmiana dotyczy bezpieczeństwa lub prywatności.

## Zgłaszanie błędów

Użyj szablonu bug report. Nie publikuj sekretów, danych osobowych ani pełnych
logów z tokenami. Luki bezpieczeństwa zgłaszaj prywatnie według
[`SECURITY.md`](SECURITY.md), nie przez publiczne issue.

## Zachowanie

Obowiązuje [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md). Moderacja może usunąć
treść lub zablokować udział w przypadku nadużyć.
